> 🔗 [Live Demo](https://smart-uzhavar.vercel.app)

farmers with AI-driven agricultural insights, real-time government data,

`NextAuth.js` · `Google Gemini API` · `Vercel`

### ✈️ Travid — Accessible AI Travel Assistant
> 🔗 [GitHub Releases — APK v1.0.0](https://github.com/CRK08/travid/releases)
> 📄 Published in **IJSREM, November 2025**

A voice-controlled, accessibility-first mobile travel assistant built
specifically for blind and visually impaired users — combining AI,
real-time navigation, and thoughtful UX into a fully functional app.

**What it does:**
- Real-time navigation using OpenStreetMap integration
- Haptic and audio feedback throughout the interface
- Offline maps support for low-connectivity scenarios
- AI-powered travel assistance via Google Gemini 2.5 Flash

**Tech Stack:**
`Flutter` · `Dart` · `Firebase` · `Riverpod` ·
`Material Design 3` · `Google Gemini 2.5 Flash` · `OpenStreetMap`

> Accessibility was not an afterthought here — it was the entire design
> philosophy from day one.
